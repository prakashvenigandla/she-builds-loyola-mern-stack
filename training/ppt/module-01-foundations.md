# Module 01 PPT | Programming and Web Foundations

**README duration:** 5 h | **Build thread:** model a campus event registration request | **Evidence:** request map + expense summary pseudocode

## Slide sequence

1. **A campus event in your pocket** (5 min) — Hook: what happens after tapping “Register”? Ask students to name the parts they can see.
2. **A web app is a team effort** (10 min) — User, browser/frontend, server/backend, database; map each to a festival registration.
3. **One request, one response** (15 min) — Draw browser → HTTP request → server → database → response. Show what changes when the server is unavailable.
4. **Programs store and transform facts** (20 min) — Variables, types, operators; use `ticketCount`, `price`, and `total`.
5. **Make a decision repeatable** (20 min) — Conditionals, loops, functions, arrays and objects through a capacity check.
6. **Think before typing** (15 min) — Turn “calculate event spend” into inputs, rules, pseudocode, and test examples.
7. **Practice, explain, exit** (10 min) — Run Demo 01, then begin Lab 01. Exit: explain one request and one condition in your own words.

## Instructor cues

Use Activity 1 as a quick role-play: students act as browser, server, and database. Let the database reject an unknown event ID. Explicitly distinguish internet, website, and web application. Do not begin with syntax memorization; students should first agree on inputs and expected outputs.
