# Module 04 PPT | React Frontend Development

**README duration:** 25 h | **Build thread:** reusable event browser | **Evidence:** searchable React UI with routes and API states

## Slide sequence

1. **From page to interface system** (5 min) — Sketch event list as header, search, event card, and empty state.
2. **Components and JSX** (20 min) — Functional components, composition, props; separate repeated event cards from page layout.
3. **State follows user intent** (20 min) — `useState`, controlled input, state vs props, lift state only when needed.
4. **Effects synchronize with the outside world** (20 min) — `useEffect` for a request, cleanup/dependencies, loading/error; distinguish event handlers from effects.
5. **Forms, navigation and data** (20 min) — Form validation, route links/parameters, API service boundary; protect routes conceptually.
6. **Design for change** (15 min) — Reusable components, responsive states, lazy loading and memoization as tools, not defaults.
7. **Build the browser** (10 min) — Run Demo 04, then Lab 04. Exit: which data belongs in props and which changes locally?

## Instructor cues

Use the project scaffold already taught by the program; do not lose the session to framework installation. Teach one state owner at a time. Treat Context as a solution to demonstrated prop plumbing, not a required default for every app.
