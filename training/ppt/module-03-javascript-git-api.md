# Module 03 PPT | Modern JavaScript, APIs and Git

**README duration:** 15 h | **Build thread:** load event data, make a reviewed change | **Evidence:** API-powered event list + pull request

## Slide sequence

1. **Data changes; interfaces adapt** (5 min) — Compare hard-coded event text with a changing event feed.
2. **Modern JavaScript is clearer JavaScript** (20 min) — `const`/`let`, arrow functions, template literals, destructuring, spread, modules; convert one small example live.
3. **A network request takes time** (20 min) — Promise lifecycle, `async`/`await`, loading/success/error states, `try`/`catch`.
4. **Read the response contract** (15 min) — HTTP status, JSON, `fetch`, public API limits, and why a failed request is normal.
5. **Git records decisions** (20 min) — status → diff → add → commit; branch and pull request; review intent, not just syntax.
6. **Debug with evidence** (15 min) — Reproduce, inspect console/network, isolate, change one thing, verify.
7. **Fetch and collaborate** (10 min) — Run Demo 03, then Lab 03. Exit: what does a loading state tell a user?

## Instructor cues

Network access can fail in a classroom. Have the demo's local data fallback ready. Do not require API keys. Emphasize that generated commit messages or AI debugging suggestions must be checked against the diff and actual behavior.
