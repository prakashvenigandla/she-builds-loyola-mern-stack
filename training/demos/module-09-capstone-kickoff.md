# Module 09 Demo | Turn an Idea into a Sprint

**Time:** 20 minutes | **Paired lab:** [Lab 09](../hands-on/module-09-capstone-studio.md)

## Prepare

Use this example brief: “Students miss campus event registration deadlines because event details are scattered.” Keep scope to browse events, view details, register, and see confirmation.

## Run it

1. Ask “Who has this problem?” Replace broad users with one persona: a student deciding whether to attend.
2. Write one story: “As a student, I can see an event's date and seats so I can decide whether to register.”
3. Define acceptance: event list displays title/date/seats; registration with available capacity confirms; full event is rejected.
4. Sketch the UI, `Event` fields, and one API request. Draw where capacity is checked.
5. Split work into a vertical slice and assign owner/reviewer; identify the first integration checkpoint.

**Expected:** a small testable plan, not a feature brainstorm. **Recovery:** if teams propose an oversized idea, time-box the MVP and move everything else to a “later” list. Save the brief as the demo output.
