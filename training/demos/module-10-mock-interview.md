# Module 10 Demo | Think-Aloud Interview

**Time:** 15 minutes | **Paired lab:** [Lab 10](../hands-on/module-10-placement-practice.md)

## Prepare

Prompt: “Given an array of event registration IDs, return the first ID that appears twice; return `null` if there is none.” Use a whiteboard, not an online judge.

## Run it

1. Candidate asks about empty input, ID type, and expected complexity.
2. Candidate traces `[4, 8, 4]` and `[1, 2, 3]` before coding.
3. Model a simple `Set`: for each ID, return if already seen; otherwise add it. Then trace edge cases.
4. Ask candidate to explain time/space cost and one test. Interviewer gives one specific piece of feedback.
5. Give a 30-second project pitch using: problem, my contribution, evidence, lesson.

**Expected:** clarification, readable reasoning, and a checked result matter more than speed. **Recovery:** if syntax stalls, accept pseudocode and ask what the candidate would verify in documentation.
