# Module 02 Lab | Event Registration Page

**Pair with:** PPT 02 slides 2–6 and Demo 02 | **Suggested time:** 2–3 hours within the 10-hour module

## Challenge

Build a responsive page for one fictional campus workshop. Required details: title, date/time, venue, short description, available seats, and a registration form. Do not collect phone numbers or real student data.

## Tasks

1. Structure the page with semantic HTML, a clear heading hierarchy, and a labeled email field.
2. Style the event details and form. Use Flexbox or Grid and add one narrow-screen layout change.
3. On submit, prevent reload, validate required input, and display a clear success or error message.
4. Test at phone and desktop widths, then navigate using only the keyboard.

## Acceptance checks

- Event details remain readable at both widths without horizontal scrolling.
- Every field has a visible label; focus is visible; feedback is announced with a status region.
- Empty/invalid submission is not reported as success; valid-looking input produces feedback.
- Student can point to the HTML, CSS, and JavaScript responsible for each behavior.

**Extension:** disable registration when the fictional seat count is zero. **Evidence:** screenshot at two widths plus a short note on one accessibility improvement.
