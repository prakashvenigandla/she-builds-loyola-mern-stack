# Module 11 Lab | AI Engineering Playbook

**Pair with:** PPT 11 slides 2–6 and Demo 11 | **Suggested time:** 2–3 hours within the 10-hour module

## Challenge

Create a reusable, bounded AI workflow for one small feature from the team's capstone. Use an approved tool or evaluate the instructor's sample output offline.

## Tasks

1. Write a prompt framework with task, audience, verified context, constraints, output format, and required assumptions/tests.
2. Ask for two implementation options and trade-offs; verify claims against course documentation or code supplied by the instructor.
3. Define a two- or three-role workflow with explicit artifacts, human approval gates, and a stop condition. Do not grant an agent secrets or deployment authority.
4. Review one generated suggestion for correctness, security/privacy, accessibility, and maintainability. Run a test or explain the manual check.
5. Create a governance checklist: approved tool, data allowed, attribution/disclosure, reviewer, evidence, retention, escalation.
6. Propose a small productivity measure that includes quality and rework, not just speed.

## Acceptance checks

- Prompt separates supplied facts from assumptions and requests verifiable output.
- Recommendation has evidence and a human-reviewed test; unsupported claims are flagged.
- Workflow cannot silently modify protected data or deploy; risks and stop conditions are explicit.
- Measurement balances time saved with defects/rework and learning.

**Evidence:** AI Engineering Playbook, reusable prompt, workflow diagram, and one completed review record. Never include confidential prompts or personal data.
