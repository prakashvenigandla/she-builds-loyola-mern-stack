# Module 10 Lab | Placement Practice Portfolio

**Pair with:** PPT 10 slides 2–6 and Demo 10 | **Suggested time:** 2–3 hours within the 6-hour module

## Challenge

Practice one coding prompt, one project explanation, and one behavioral response. Give feedback as a peer, not as a gatekeeper.

## Tasks

1. Solve the duplicate-ID prompt from Demo 10. State assumptions, trace two examples, implement, and test an edge case.
2. Give a 90-second capstone pitch that separates team work from your contribution.
3. Answer “Tell me about a time you got stuck” with a genuine situation, action, result, and lesson.
4. Review one portfolio repository: run instructions, project purpose, screenshots, tests, contribution clarity, and live link.
5. Choose one improvement and complete it (for example, clarify README setup or add a missing test).

## Acceptance checks

- Solution handles duplicate and no-duplicate input; student explains the Set lookup.
- Pitch includes a user problem, individual contribution, and verifiable evidence.
- Peer feedback is specific and respectful; portfolio claims match the repository.
- Student leaves with one actionable next step.

**Extension:** solve a string-frequency or binary-search prompt and compare trade-offs. **Evidence:** solution, revised project README/portfolio, and a short reflection.
